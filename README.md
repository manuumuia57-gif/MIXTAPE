# DeKUT Past Papers Library

**Dedan Kimathi University of Technology**  
> *"Access. Revise. Prepare. Succeed."*

A modern, fast, mobile-friendly academic resource repository for Dedan Kimathi University of Technology (DeKUT) students and a private single-administrator management console.

## Features
- **Public Student Website (No Login Required)**: Browse, search, and filter past examination papers, CATs, lecture notes, assignments, practical sheets, and revision materials by School/Faculty, Department, Course, Academic Year, Semester, and Examination Type.
- **Built-in PDF Viewer**: Preview PDFs inline with page navigation, zoom in/out, full-screen mode, and one-click downloads.
- **Private Admin Dashboard**: Protected by administrator login (no public registration). Includes:
  1. Dashboard (KPI counts, recent documents, student contact messages)
  2. Upload New Material (drag-and-drop & file browser for PDF/DOCX/PPTX with progress bar)
  3. Manage Past Papers (edit details, replace file, delete with confirmation)
  4. Manage Study Materials (edit details, replace file, delete with confirmation)
  5. Manage Courses (add, edit, delete, assign to departments)
  6. Manage Departments (add, edit, delete, assign to schools/faculties)
  7. Website Settings (site info, contact info, academic years, change admin credentials)
  8. Logout
